FEATURES
- Animated palace gate entrance based on the uploaded plabini reference project
- Personalized A & T monograms, hero, countdown and envelope invitation
- Eight event cards, accurate times and individually downloadable calendar invites
- Wedding/reception directions, contact links, WhatsApp-ready RSVP composer
- Accessible responsive layout, supplied couple story photo, and Memories placeholder
- Source files: index.html, styles.css, script.js, assets/, calendar/

EDITING
- To change displayed content, edit index.html. To change colours/fonts/layout, edit styles.css. To change the countdown or RSVP behaviour, edit script.js.
- To change times, update the event text and datetime attributes in index.html AND the corresponding .ics file in calendar/ and celebrations.ics.
- The entrance and event imagery are illustrative, not photos of the actual venue. The story photo is the couple's supplied photo.
- The Memories dialog displays a coming-soon message until you provide your own photos.
- RSVP never automatically submits or saves personal information. It prepares a message for you to send using WhatsApp or copy manually.
- No copyrighted music from the original repository has been included.

UPLOAD TO GITHUB PAGES
1. Create a new repository or use a repository you own.
2. Upload the CONTENTS of this folder into the repository root.
3. In Settings -> Pages choose Deploy from a branch, main, / (root).
4. Your site will be live at the Pages URL. This archive has not been pushed to any repository.
